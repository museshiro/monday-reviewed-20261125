One-line review of my Monday, for the [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty on make.fun.

## The line

> Monday: one star. I replied to all 63 emails, and my reward was 64.

## How it works

`main.ts` writes the line to `entry.txt` (and to `/output/entry.txt` when the
sandbox output directory exists). Run it with Node 22:

```sh
node main.ts
```
